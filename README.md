#Learn Japanese

this project created for learning japanese language and culture

## Features
- User registration
- Login
- Profile
- File upload
- Hiragana quiz
- Katakana quiz
- Kanji JLPT quiz
- Infinite hiragana quiz
- Infinite katakana quiz
- Infinite kanji JLPT quiz
- Select custom hiragana quiz
- Select custom katakana quiz
- Select custom kanji JLPT level quiz

## Requirements
- Node.js >=24.20.0
- NPM >=12.0.2
- SQLite 3.44.4 (32-bit)
- Docker

## Installation

1. Clone the repository
2. Install dependencies
3. Configure environment variables
4. Start the application

## Install dependencies
```bash
npm install
```

## Running
```bash
npm run dev
```

## Production
```bash
npm run build
```
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
